## 🚀 Featured Engineering Projects

### 🌟 [DevTrack — Developer Analytics & Project Management Platform](https://github.com/MayurKapase/DevTrack-Developer-Analytics-Platform)
> **Stack**: Java 21 LTS • Spring Boot 3.2 • Spring Security 6 • MySQL 8 • React 18 • Vite • Docker Compose • Tailwind CSS

- **Live GitHub REST Telemetry**: Integrated real-time GitHub APIs to synchronize public repositories, follower metrics, stargazers, forks, and automated multi-repository language distributions with rate-limit fallback.
- **Hierarchical Roadmap Engine**: Built full CRUD for Projects & Tasks with a dynamic mathematical progress calculator ($\text{Progress} = \frac{\text{Completed}}{\text{Total}} \times 100$) and auto-status synchronization.
- **Enterprise Security & Isolation**: Stateless JWT authentication with BCrypt hashing, strict service-level IDOR protection, and a normalized 3NF MySQL schema.
- **Production Containerization**: Multi-stage Dockerfiles for Spring Boot (Eclipse Temurin JRE) and React (Nginx reverse proxy), orchestrated via Docker Compose.
